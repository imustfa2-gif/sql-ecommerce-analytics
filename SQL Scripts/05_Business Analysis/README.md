# Business Analysis Scripts

The business analysis is separated by topic so each script can be executed and reviewed independently.

| Order | Script | Focus |
|---|---|---|
| 1 | `01_Executive_KPIs.sql` | Orders, delivery and cancellation rates, revenue, and AOV |
| 2 | `02_Revenue_Trends.sql` | Monthly trends, date coverage, and top months |
| 3 | `03_Product_Analysis.sql` | Categories and individual products |
| 4 | `04_Customer_Analysis.sql` | Unique customers, repeat rate, spenders, and states |
| 5 | `05_Payment_Analysis.sql` | Payment methods and installments |
| 6 | `06_Delivery_Analysis.sql` | Delivery duration, outliers, and late-delivery KPIs |
| 7 | `07_Review_Analysis.sql` | Review distribution and delivery-related satisfaction |
| 8 | `08_Seller_Analysis.sql` | Seller sales, reviews, and delivery performance |
| 9 | `09_Freight_Analysis.sql` | Freight burden overall and by customer state |

The `Archive` folder retains the original combined analysis script for reference. The numbered scripts are the organized portfolio version.

Run the scripts after creating, loading, and validating the database. Each file includes its business questions, SQL queries, recorded results, and business insights.
