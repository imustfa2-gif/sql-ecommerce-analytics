# E-Commerce Analytics SQL Project

## Project Overview

This project focuses on designing and building a relational database for an e-commerce business using Microsoft SQL Server.

Instead of starting directly with data analysis, the project follows a structured workflow that begins with database design, data loading, and data validation to ensure data quality before extracting business insights.

The project is divided into three main phases:

- Phase 1: Database Design & Data Preparation
- Phase 2: SQL Business Analysis
- Phase 3: Power BI Dashboard & Data Visualization

---

## Project Objectives

- Design a normalized relational database.
- Build relationships using Primary Keys and Foreign Keys.
- Import raw CSV files into SQL Server.
- Validate data quality and integrity.
- Identify and document data quality issues.
- Perform business analysis using SQL.
- Build interactive dashboards using Power BI.
